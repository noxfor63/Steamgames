# Ресурсы и лицензии

Все игровые ресурсы поставляются с репозиторием. Во время игры сеть для загрузки ресурсов не нужна.

- **Геометрия, интерфейс и значок:** авторский код этого проекта. Готовые модели и шаблонные сцены не использовались. В `hands.js` добавлена собственная геометрия перчаток, пальцев, манжет, рукавов и двуручного тигля; захваты и наклон анимируются кодом.
- **Материалы:** карты камня, металла и керамики создаются локально детерминированным алгоритмом в `scene.js`. Это процедурные текстуры, не фотосканирование. Свечение — локальная радиальная текстура. Море — анимируемая геометрия и нормали.
- **Окружение отражений:** RoomEnvironment из Three.js, MIT. Используется для освещения и отражений, не как игровая локация.
- **Three.js 0.187.0 и дополнительные модули:** MIT, `dist/vendor/THREE-LICENSE.txt`. Воспроизведение поставки: `npm ci && npm run vendor`.
- **Cormorant Garamond, Manrope:** Google Fonts, SIL Open Font License. Файлы в `dist/assets`; лицензии `cormorantgaramond-OFL.txt` и `manrope-OFL.txt`. Источники лицензий: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond и https://github.com/google/fonts/tree/main/ofl/manrope . Загружены в локальную поставку; удалённые CSS или шрифты при игре не используются.
- **Звук:** собственный Web Audio синтез, без сторонних записей. Подробности в [AUDIO.md](AUDIO.md).

Пробное обращение к API Poly Haven не дало доступа; ни один ресурс оттуда в сборку не включён.
