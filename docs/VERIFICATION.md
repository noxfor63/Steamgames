## Граница проверки

Новая браузерная попытка после запуска Cloud desktop: `sites-preview start /workspace/sites/springtown` вернул `relay could not open browser port 4173: timed out waiting for relay readiness`. `sites-preview status` показал остановленный предпросмотр. Альтернативный сервер и обход инфраструктуры не использовались.

Не подтверждены реальным браузером: видимый кадр с руками, компиляция шейдеров, частота кадров, захват курсора, читаемость узкого экрана, сенсорные жесты и звучание. Математические тесты преобразований рук не подтверждают художественное качество анимации. Скриншоты результата не сделаны.
