# Проверка «Литейщика великанов»

Дата: 27 ноября 2026 года.

## Выполнено

- `npm test`: 12 тестов пройдены. Девять проверяют игровые правила и сохранения, три — построение геометрии изделий.
- Проверены: отсутствие заливки без действия; неизменность входного состояния; переходы заливка/охлаждение/раскрытие; однократные награды; запрет преждевременного перехода; стоимость улучшений; прохождение всех девяти частей; сохранение в середине охлаждения; восстановление коллекции; фильтрация повреждённых данных; ограничение больших шагов времени.
- Автоматический прогон завершает коллекцию за 176,4 секунды непрерывной работы при немедленной покупке доступных улучшений. Это не тест удержания и не четырёхчасовая кампания.
- Для каждой модели проверены непустая объёмная геометрия, конечные координаты и разумный размер. У небесного атласа есть три независимых кольца.
- `node --check` для игровых модулей; `git diff --check`.
- Статическая проверка локальных модулей и файлов ресурсов проведена отдельно. Шрифты и их OFL-лицензии включены в поставку.

## Граница проверки

Браузерный предпросмотр **не проверен**. Поддерживаемый `sites-preview start /workspace/sites/springtown` дважды вернул `relay could not open browser port 4173: timed out waiting for relay readiness`; вторая попытка сделана после запуска Cloud desktop. `sites-preview status` показал остановленный предпросмотр. Альтернативный сервер и обход инфраструктуры не использовались.

Поэтому не подтверждены: видимый кадр, компиляция шейдеров реальным браузером, частота кадров, читаемость мобильного экрана, точность указателя, фактическое прослушивание звука. Проверки правил и геометрии не заменяют эти проверки. Скриншот результата не выдаётся за сделанный.

Проверить рабочий и узкий экран, сенсорный ввод, оба режима качества.
