# Звук мастерской

Собственный процедурный звук в `dist/audio.js`, без скачанных аудиозаписей и без сторонних лицензируемых семплов.

Морской фон: мягкий фильтрованный шум с медленным изменением уровня. Печь: тихие низкие синусоидальные составляющие. Заливка: отдельные слои низкого потока и более высокого шороха с меняющимся спектром. Открытие оболочки: короткий затухающий шум и низкие металлические составляющие. Завершение: мягкое трёхзвучие с нецелыми обертонами. Компрессор ограничивает резкие пики.

Контекст звука создаётся только после жеста игрока. При паузе звучание плавно затихает; громкость регулируется и сохраняется. Синтез не требует сети. Это технически проверенный код звука; прослушивание в браузере пока не выполнено из-за недоступного предпросмотра.
