# Литейщик великанов

Выбранная пользователем 27 ноября 2026 года идея: спокойное литьё, из которого постепенно вырастает собственный город. Первая оформленная игровая сцена — приморская мастерская с девятью отливками и тремя изделиями: фонарём, фонтаном и армиллярной сферой.

## Что сделано

- Полноценная 3D-сцена: каменная терраса, аркада, печь, море, дальний берег, растения, инструменты и набережная.
- Собственные модели изделий с профилированной бронзой, декоративными кольцами и деталями. Процедурные карты шероховатости, мягкие тени, отражения окружения, свечение металла.
- Заливка непрерывной струёй, постепенное появление отливки, остывание и раскрытие керамической оболочки. Передняя часть формы показана в разрезе для удобного наблюдения.
- Девять этапов, три приобретаемых улучшения тигля: поток 2,2 → 8 → 22 → 48 кг/с. Нет наказаний, ограниченного запаса сырья или обязательного точного прицеливания.
- Готовые изделия остаются на набережной. Фонарь светится, фонтан получает струи воды, кольца сферы вращаются.
- Рабочий ракурс с вращением и приближением; отдельная прогулка от первого лица. Локальные сохранения, подтверждение сброса, пауза, громкость, качество графики, чувствительность и уменьшение движения.
- Авторский процедурный звук: морской фон, печь, поток металла, открытие формы и металлические созвучия. Все ресурсы локальные, внешних запросов при игре нет.

Это браузерная версия для оценки материала, управления и выбранной механики. Это ещё не Steam-сборка и не многочасовая кампания. Автоматический прогон с непрерывной заливкой и немедленными улучшениями проходит девять отливок за **176,4 секунды**, без времени на осмотр, прогулку и решения игрока. Продолжительность обычной сессии ещё не измерена.

## Запуск

Из корня репозитория на своём компьютере:

```sh
python3 -m http.server 3000 --directory dist
```

Открыть `http://localhost:3000` в браузере с WebGL 2. В управляемом окружении Codex использовать поддерживаемый `sites-preview start /workspace/sites/springtown`. Файлы через `file://` не запускать: используются ES-модули.

## Управление

- ЛКМ на сцене — удерживать заливку. Пробел или кнопка «Лить бронзу» — постоянный поток.
- ПКМ с перетаскиванием — обзор; колёсико — приближение к рабочей форме.
- G — перейти между рабочим ракурсом и прогулкой; WASD — ходьба; стрелки — обзор во время прогулки.
- E — приобрести доступное улучшение. R — восстановить удобный ракурс. Esc — пауза.
- На сенсорном экране: перетаскивание сцены для обзора, кнопка постоянной заливки и кнопки ходьбы.

Сохранения остаются на этом устройстве в этом браузере. Ключи сохранений предыдущих экспериментов не затрагиваются.

## Разработка и проверка

```sh
npm ci
npm test
npm run vendor
```

Three.js 0.187.0 и используемые модули включены в `dist/vendor`. `engine.js` — чистые правила; `scene.js` — геометрия и визуализация; `app.js` — интерфейс, ввод и сохранение; `audio.js` — синтез звука.
