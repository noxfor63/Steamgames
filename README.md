# Город на пружине

Играбельный браузерный прототип о восстановлении механического города. В эпизоде «Нижний порт» нужно очистить и починить поезд, кран и мельницу, подключить их к общей пружине и завершить три работы.

Это короткая проверка механики на несколько минут. Полная кампания на 6–8 часов и выпуск в Steam пока не реализованы.

Основной репозиторий: [noxfor63/Steamgames](https://github.com/noxfor63/Steamgames).

## Запуск

Нужны Python 3 и современный браузер. Из корня проекта:

```sh
python -m http.server 3000 --directory dist
```

Откройте `http://localhost:3000`. Запускайте через HTTP: ES-модули могут не работать при открытии `index.html` как локального файла.

Сборка и установка зависимостей не нужны. Шрифты Golos Text и Prata загружаются через Google Fonts; без сети используются системные замены. Код, отрисовка и игровой звук работают локально.

## Управление

- Выберите механизм на макете или кнопками «Поезд», «Кран», «Мельница».
- Щётка: удерживайте кнопку мыши или палец и водите по механизму до полной очистки.
- Ремонт: установите шестерню кнопкой справа либо инструментом «Ремонт».
- Ремень: подключите или отключите восстановленный механизм.
- Редуктор можно поставить на поезд или кран, затем свободно переставлять.
- Кнопка «Завести город» запускает привод. Перегрузка приостанавливает работу, ничего не ломая.
- Доставка деталей поездом или расчистка пристани краном открывает переключатель: поезд и кран работают по очереди, мельница — постоянно.

Клавиши `1`, `2`, `3` выбирают инструменты; `Пробел` запускает или останавливает привод, если фокус находится на игровом поле страницы; `Ctrl+Z` / `Cmd+Z` отменяет последнее действие. Очистка требует указателя. Звук включается кнопкой с нотой.

Прогресс сохраняется в `localStorage` этого браузера. После перезагрузки привод остановлен; его можно завести снова. Новая игра запускается через меню с подтверждением. Облачной синхронизации сохранений нет.

## Проверки

Нужен Node.js 18 или новее:

```sh
npm test
```

Тесты проверяют порядок восстановления, оба маршрута прохождения, перегрузку, перенос редуктора, неизменность входного состояния, повреждённые сохранения и расчёт времени при разной частоте кадров.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `dist/index.html` | Экран игры, панели и диалоги |
| `dist/style.css` | Адаптивный интерфейс |
| `dist/scene.js` | Авторский макет на Canvas 2D, анимация и выбор объектов |
| `dist/engine.js` | Чистые функции правил и игрового состояния |
| `dist/app.js` | Ввод, интерфейс, сохранения, звук и игровой цикл |
| `tests/engine.test.mjs` | Автоматические проверки правил |
| `docs/DESIGN.md` | Решения прототипа и дальнейшие гипотезы |
| `.openai/hosting.json` | Конфигурация публикации Sites; существующий идентификатор сохраняется |

В проекте нет серверной части, аналитики, аккаунтов и Steamworks. Секреты и локальные рабочие файлы в репозиторий не добавляются.
