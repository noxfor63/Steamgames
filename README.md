# Большой вдох — 3D-прототип

Рабочая гипотеза для спокойной игры в Steam: восстановить сдутый приморский парк. Направляешь насадку и удерживаешь кнопку; плоские формы расправляются и становятся огромными игрушками, арками, китами и воздушным кораблём. Одинаковый жест постепенно даёт намного больший результат.

Это короткая проба механики в настоящем WebGL 3D от первого лица, а не готовая Steam-игра. В ней 27 объектов, семь ступеней инструмента (поток от 4 до 2916 условных литров в секунду), одновременное воздействие до 12 целей и локальное сохранение. Баланс ускорен. Четырёхчасовой кампании здесь пока нет.

## Запуск

Все ресурсы уже находятся в `dist/`, включая зафиксированную Three.js и её MIT-лицензию. Для просмотра нужен HTTP-сервер и браузер с WebGL 2. Открытие `index.html` через `file://` не подходит для ES-модулей.

На своём компьютере из корня репозитория:

```sh
python3 -m http.server 3000 --directory dist
```

Затем открыть `http://localhost:3000`. Для управляемого окружения Codex используется только поддерживаемый `sites-preview start /workspace/sites/springtown`.

## Управление

- WASD — ходьба, Shift — быстрее, мышь — обзор.
- Удерживать ЛКМ — надувать; F или кнопка «Включить поток» — непрерывный поток без удержания.
- E или кнопка улучшения — следующая ступень инструмента.
- Esc — пауза. При недоступном захвате курсора: обзор правой кнопкой с перетаскиванием или стрелками клавиатуры.
- На сенсорном экране: кнопки ходьбы, перетаскивание сцены для обзора, кнопка потока.
- Звук включается отдельно; в паузе есть уменьшение движения и подтверждение сброса.

Формы не теряют воздух, нет таймеров, поражения, переноски добычи, сортировки или прокладки шлангов. Сохранение остаётся в этом браузере на этом устройстве; синхронизации Steam Cloud пока нет.

## Разработка

```sh
npm test
```

Тесты не требуют установки Three.js. Если нужно обновить или восстановить поставку библиотеки:

```sh
npm ci
npm run vendor
```

`dist/engine.js` содержит чистую игровую модель, `dist/scene.js` — геометрию и рендеринг, `dist/app.js` — ввод, интерфейс, звук и сохранение. Текущая технология выбрана для быстрой проверки действия в браузере; производственный движок и бюджет Steam-версии ещё не утверждены.
